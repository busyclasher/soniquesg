## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. The WhatsApp trial conversion uses Google Ads conversion ID `AW-17410301876` and label `CG7KCK289rgcELS_8O1A`. Set `GOOGLE_ADS_CONVERSION_LABEL` only if Google Ads gives you a replacement label later.
4. Run the app:
   `npm run dev`
