## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Set `GOOGLE_ADS_CONVERSION_LABEL` in [.env.local](.env.local) to the label from the Google Ads conversion action. The site already uses conversion ID `AW-17410301876`.
4. Run the app:
   `npm run dev`
